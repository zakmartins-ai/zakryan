O que é a Água Virtual?

Trata-se da quantidade invisível de água utilizada em todas as etapas da cadeia produtiva de um item. De roupas a eletrônicos, tudo consome água antes de chegar às suas mãos.

⚡ Atalhos Produtivos no VS Code

Digite para buscar um comando específico:

  • Ctrl + Shift + L — Seleciona todas as ocorrências do texto/palavra selecionada.
  • Alt + Z — Ativa/Desativa o Word Wrap (quebra automática de linha).
  • Ctrl + Shift + K — Deleta a linha inteira onde o cursor está posicionado.
  • Ctrl + Enter — Insere uma nova linha abaixo sem quebrar a linha atual.
  • Ctrl + Shift + Enter — Insere uma nova linha acima.
  • Ctrl + G — Vai direto para um número de linha específico.
  • Ctrl + K Ctrl + C — Comenta o bloco selecionado.
  • Ctrl + K Ctrl + U — Descomenta o bloco selecionado.
  • Ctrl + \ — Divide a tela do editor em duas colunas.
